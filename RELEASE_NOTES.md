# SwipeSelection Reborn 1.0.1

SwipeSelection Reborn 1.0.1 is a maintenance release containing internal code cleanup. There are no user-facing behavior changes.

## Changes

- Silenced unused callback parameters.
- Used dispatch_once for the settings defaults.
- Replaced floorf with floor for CGFloat frames.
- Centralized the preferences notification name.
- Enabled -Wall -Wextra for both targets.

## Compatibility

Requires iOS 16.0 or later. Rootless and roothide packages are included.
