# SwipeSelection Reborn 1.0.0

SwipeSelection Reborn 1.0.0 is the first public release of the swipe-to-move
keyboard tweak for jailbroken iOS 16 and later.

## Highlights

- Swipe across the keyboard to move the caret.
- Swipe from Shift or Delete to select text.
- Native keyboard dim during the gesture.
- Adjustable cursor speed with a 1.00 default.
- Optional haptic feedback.
- Space/Shift/Delete-only activation mode.
- WebKit/CodeMirror selection through the page's own selection model.
- Rootless and RootHide packages.

## Compatibility

| Build | Architecture | Compatibility |
|---|---|---|
| RootHide | `iphoneos-arm64e` | Tested on iOS 16 (palera1n, RootHide) and iOS 18 (Dopamine 3, RootHide) |
| Rootless | `iphoneos-arm64` | Expected to work on iOS 16+ rootless jailbreaks |

## Install

1. Download the deb matching your jailbreak.
2. Install it with Sileo, Zebra, or Filza.
3. Respring.
4. Open **Settings → SwipeSelection Reborn** to configure it.

## Verification

Verify the downloaded deb against `SHA256SUMS.txt` before installing.
